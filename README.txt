# 🦷 Aplicación Web para la Gestión de Citas – Clínica Dental Tatiana Maldonado (Esmeraldas)

## 📌 Descripción del Proyecto
Este proyecto corresponde al desarrollo de una **aplicación web completa** para la gestión de citas en la Clínica Dental Tatiana Maldonado, ubicada en Esmeraldas.  
El sistema permite administrar pacientes, citas y recordatorios de manera eficiente, integrando un **panel administrativo** y una **interfaz amigable para usuarios**.

---

## 🚀 Tecnologías Utilizadas
- **[Django](ca://s?q=Framework_Django)** y **[Python](ca://s?q=Lenguaje_Python)** – Backend y lógica de negocio.  
- **[MySQL](ca://s?q=Base_de_datos_MySQL)** – Base de datos relacional.  
- **[HTML](ca://s?q=Lenguaje_HTML)**, **[CSS](ca://s?q=Lenguaje_CSS)**, **[JavaScript](ca://s?q=Lenguaje_JavaScript)** – Frontend dinámico.  
- **[PHP](ca://s?q=Lenguaje_PHP)** y **[C#](ca://s?q=Lenguaje_C_Sharp)** – Módulos complementarios y pruebas de integración.  

---

## 🧩 Módulos Principales
- **[Registro de usuarios](ca://s?q=Módulo_registro_de_usuarios)**: pacientes y personal administrativo.  
- **[Agendamiento de citas](ca://s?q=Módulo_agendamiento_de_citas)**: selección de fecha, hora y odontólogo.  
- **[Recordatorios automáticos](ca://s?q=Módulo_recordatorios_de_citas)**: vía correo electrónico o WhatsApp.  
- **[Panel administrativo](ca://s?q=Panel_administrativo_en_aplicaciones_web)**: gestión de usuarios, citas y reportes.
